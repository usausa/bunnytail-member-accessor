# Diagnostics

| ID | Severity | Description | How to fix |
|---|---|---|---|
| BTMA0001 | ❌ Error | Type given for closed generic accessor generation is not a generic type | Specify a generic type, or remove the closed generic specification |
| BTMA0002 | ❌ Error | Closed generic specification is not declared on the matching open generic definition | Move the attribute onto the open generic type it closes over |
| BTMA0003 | ❌ Error | Type has no accessible members and no public constructor written in it to generate an accessor for (the default constructor the compiler adds does not count) | Add an accessible member or a public constructor, or remove `[GenerateAccessor]` |
| BTMA0004 | ❌ Error | Target type of `[TypedAccessor]` is not decorated with `[GenerateAccessor]` | Add `[GenerateAccessor]` to the target type, or use `[GenerateAccessorFor]` |
| BTMA0005 | ❌ Error | Constructor has more parameters than the generator supports | Reduce the constructor parameters, or exclude the type |
| BTMA0006 | ℹ️ Info | Provider class is not `partial`, is `static` or `file`-local, or a type containing it is not `partial`, so the `IAccessorProvider` implementation is not generated | Declare the class and every containing type as `partial`, and the class as non-static, if the provider implementation is needed |
| BTMA0007 | ❌ Error | Target type of `[GenerateAccessorFor]` is not supported (not a class or struct, `static`, a `ref struct`, nested, `file`-local, or not accessible) | Specify a supported target type |
| BTMA0008 | ℹ️ Info | Target type already has accessors generated by `[GenerateAccessor]`, and the attribute neither implements the provider interfaces nor registers a closed generic type | Remove the redundant `[GenerateAccessorFor]` |
| BTMA0009 | ❌ Error | Non-public member access on a generic type needs `UnsafeAccessor` with generic parameters, which requires .NET 9 or later | Target .NET 9 or later, or access only public members |
| BTMA0010 | ❌ Error | `[GenerateAccessor]` nested type, or a type containing it, is generic | Make the nested type and every containing type non-generic, or move the type out of the generic type |
| BTMA0011 | ❌ Error | `[GenerateAccessor]` type, or a type containing it, is `private`, `protected` or `file`-local, so the generated accessor cannot reference it | Make the type and every containing type `internal` or `public`, and not `file` |
| BTMA0012 | ❌ Error | `[GenerateAccessor]` type is a `static` class or a `ref struct`, whose instance cannot be handled as `object` | Remove `[GenerateAccessor]` |
| BTMA0013 | ❌ Error | The name of a type to generate an accessor for differs only in case from another in the same namespace, so its accessor is not generated (generated file names are compared ignoring case) | Rename one of the types |
